# Albumiv 调整清单（v1.4.9）

> 从 [美术与交互统一性调优稿](美术与交互统一性调优稿-2026-11.md) 抽出的可执行清单，只列"要动手的"，不重复论证。
> 优先级以本清单为准；与文稿附录 B 相比有三处调整：`C-06 卡片边界`、`B-02 Pixiv 白块` 提前到 P0（改动小、观感收益直接），`I-03 选择模式两套操作` 与 `I-04 副栏` 合并为一项。
> 每条都带**验收**：验收不过，不算完成。

## 总览

| 优先级 | 项数 | 预估 | 目标 |
| --- | --- | --- | --- |
| **P0 立即** | 10 | 4–5 人日 | 止血：可读、可点、不白闪、不迷路 |

| 合计 | **39** | 27–35 人日 | — |

如果只有三天，按这个顺序做：**P0-01 → P0-02 → P0-03 → P0-04 → P0-06 → P0-07**。

## P0 · 立即（两周内）

### P0-01 建立可访问强调色板

- [ ] 每个强调色定义 6 个角色：`hue / fill / onFill / textLight / textDark / container`；把"强调色当正文"的调用点（设置值行、顶栏应用/播放、清理命令、查看器 tint）全部换成 `accent.text`。
- 文件：`ui/theme/Color.kt`、`ui/theme/Theme.kt`、`SettingsScreen.kt`、`VaultTopBar.kt`、`CleanupScreen.kt`、`MediaViewer.kt`
- 验收：`ContrastTest` 覆盖 7 色 × 2 主题；正文 ≥4.5、填充按钮 `onFill` ≥4.5；默认蓝、金、橙、玫红、森林绿全部通过。
- 依据：§3.1、§8.2

### P0-02 深色系统栏与启动背景

- [ ] 增加 `values-night/themes.xml`；按 App 内 `darkTheme` 动态设置 `isAppearanceLightStatusBars` / `isAppearanceLightNavigationBars`；配 `windowSplashScreenBackground`（API 31+）。
- 文件：`res/values/themes.xml`、`res/values-night/`、`MainActivity.kt`
- 验收：系统浅色 + App 内深色，状态栏时间/电量可见；冷启动不先白后黑；API 26/31/35 各看一次。
- 依据：§3.5、§7.6

### P0-03 底栏全标签 + Tab 语义

- [ ] 删除 `labelAlpha = if (selected) 1f else 0f`；5 个标签常显，未选中 60% 墨色；选中 = 实心图标 + 强调色 + 2dp 下划线；用 `selectable(selected, role = Role.Tab)` 替代 `clickable` + 中文 `stateDescription`。
- 文件：`ui/AppBottomBar.kt`
- 验收：5 个标签在 360dp 宽、2.0 字体下都可读；TalkBack 播报"相册，标签，已选中，1/5"。

### P0-04 选择模式只留一套操作面

- 依据：§3.6 I-03/I-04、§5.2

## 完成定义（DoD）

每一项完成时必须同时满足：

1. 有 **before/after 截图**（light + dark；涉及字体缩放的项加 2.0）。
2. `ContrastTest`、`MissingTranslationTest`、关键触控断言通过。
3. `testDebugUnitTest lintDebug` 通过；不新增 lint baseline 告警。
4. `ui/screens/` 不新增 `fontSize =`、`Color(0x`、`RoundedCornerShape(` 裸值（白名单除外）。
5. TalkBack 关键路径不回归：底栏 → 时间轴 → 多选 → 删除 → 撤销。
6. PR 描述里引用清单 ID（如 `P0-04`），方便回溯。

## 不要顺手做

- 不要在修 P0 的同一 PR 里重做页面布局——评审无法区分"修 bug"和"换设计"。
- 不要为了统一而删除 7 套强调色；只修色阶。
- 不要给缩略图加大圆角、阴影、白边；内容优先是资产。
- 不要把设置里的说明文字删掉来"变简洁"；用分组和折叠解决长度。
- 不要引入云端字体、分析 SDK 或 Material You 动态取色。
